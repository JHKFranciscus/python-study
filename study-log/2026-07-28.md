# 막힌 점

- 클래스 속성을 클래스 이름 없이 `book_count += 1`로만 써서, 지역 변수로 취급되는 오류가 났다.
- 독립 재현에서 가격 검사 함수가 정수와 `None`과 `False`를 섞어서 반환했다. 가격이 0이면 반환값이 `0`인데 `0 == False`가 참이라, 정상적인 0원이 실패로 걸러졌다.
- 그 과정에서 정수로 변환한 값에 문자열 메서드인 `strip()`을 써서 오류가 났다.
- 도서를 찾지 못했을 때 반환되는 `None`을 처리하지 않은 부분이 있었다.

# 시도한 것

- 클래스 속성은 `Book.book_count`와 `cls.book_count`처럼 클래스를 명시해서 접근했다.
- 가격 검사 함수는 `True`와 `False`만 반환하도록 수정했다. 가격 검사는 성공 여부를 판단하는 일이라, 성공과 실패를 그대로 나타내는 값이 읽기 좋다고 판단했다.
- 입력값을 정수로 변환한 뒤, `change_price()`의 반환값으로 성공 여부를 판단했다.
- 정수로 변환한 값에 쓰던 `strip()`은 삭제했다.
- 검색 함수를 호출한 메서드에서 결과가 `None`인지 `is None`으로 검사해 처리했다.
- 별도의 Python 파일에서 객체 참조 결과를 직접 실행해 확인했다.
- `remove()`로 객체를 하나 삭제한 뒤 `book_count`를 확인했더니 값이 그대로였다.

# 배운 것

- 인스턴스 속성은 객체마다 따로 가지는 값이고, 클래스 속성은 클래스가 공유하는 값이다.
- 메서드는 다루는 대상에 따라 인스턴스 메서드, 클래스 메서드, 정적 메서드로 나눌 수 있다.
- 반환값은 용도에 맞게 구분한다. 검색 함수는 찾은 객체 또는 `None`을 반환하고, 검사나 변경 함수는 성공 여부를 `True`와 `False`로 반환할 수 있다.
- `0 == False`는 참이다. 값과 `False`를 함께 반환하면 0을 실패와 구분할 수 없다.
- 리스트에 담긴 객체와 검색 함수가 반환한 객체는 같은 객체를 가리킬 수 있다.
- `__init__`에서만 `book_count`를 올렸기 때문에, 리스트에서 객체를 삭제해도 `book_count`는 자동으로 줄어들지 않는다.

# 아직 모르는 것

- 입력 검증과 형 변환을 어느 함수가 맡아야 하는지 아직 판단이 서지 않는다. 정수로 변환한 값에 `strip()`을 쓴 것도 변환을 어디서 할지 정해두지 않아서 생긴 일이다.
- `type(self)`로 접근하는 방식과 클래스 이름을 직접 쓰는 방식의 차이는 더 학습해야 한다.
