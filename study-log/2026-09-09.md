- PATCH / DELETE 후 현재 filter 값을 다시 읽어 같은 조건으로 GET 재조회했다.

## 시도한 것

record 하나의 실제 값을 고정해 놓고, 그 값을 아래 순서로 끝까지 따라갔다.

```
record → property → argument → parameter → URL/body → Flask → MongoDB
```

DOM도 실제 부모·자식 구조를 그려 가며 확인했다.
독립 재현에서 난 오류는 실행 결과를 확인하고 Claude의 교정을 받아 수정했다.

---

## 배운 점 — 핵심 두 가지

**1. `fetch()`는 HTTP 400 / 404 / 500을 받아도 자동으로 rejected되지 않는다.**
Response 자체는 정상적으로 받았기 때문이다. 그래서 `response.ok`를 검사하고 `throw`해야 정상 처리와 `.catch()` 흐름을 분리할 수 있다.

**2. `appendChild()`는 element를 복사하지 않는다.**
부모에 연결하는 것이고, 이미 다른 부모에 붙어 있으면 그 element를 이동시킨다.

## 아직 부족한 부분

큰 Flask / HTML / JavaScript 구조는 요구사항을 보고 구성할 수 있다.
다만 긴 코드에서 변수의 현재 값·type·collection/element·DOM 위치·argument/parameter를 끝까지 정확하게 추적하는 능력은 아직 독립 완성 수준이 아니다.
