## 2. 막힌 점 → 시도 → 배운 점

**① 위치 혼동 (개념)**
- 막힘: 지금 terminal이 PowerShell / local WSL / remote EC2 중 어디인지 자주 헷갈렸다.
- 시도: prompt로 구분, EC2 접속 후 whoami · hostname · pwd로 확인
- 배움: EC2는 local PC와 별개의 remote computer다. 같은 Ubuntu처럼 보여도 WSL ≠ EC2.

**② SSH Connection timed out (network 단계)**
- 막힘: Security Group에 등록된 IP와 현재 public IP가 달랐다.
- 시도: 현재 public IP와 Security Group Source 비교
- 배움: timed out은 network 단계부터 확인한다.

**③ MongoDB 설치 실패 (설치 단계)**
- 막힘: GPG key 문제로 repository 검증 실패 → mongodb-org 설치 불가
- 시도: GPG key와 repository 설정 다시 구성
- 정리: 이런 긴 설치 명령은 외우는 게 아니라 필요할 때 문서를 보고 쓰는 영역이다.

**④ HTTP 500 / 404 (application 단계)**
- 막힘: template 이름 불일치 → 500, static JavaScript file 이름 불일치 → 404
- 시도: Flask traceback과 request path 확인
- 배움: 500은 traceback부터, 404는 요청한 path/resource부터 본다.

## 3. 오늘 개념 정리

- **IP** = 어느 computer로 / **port** = 그 computer 안의 어느 service로
- **Public IPv4** = 인터넷에서 EC2 접근 / **Private IPv4** = AWS 내부 network
- **localhost** = 현재 process가 실행되는 computer 자기 자신 → EC2의 Flask에서 localhost:27017 = 같은 EC2의 MongoDB
- **외부 접속 조건 2개:** Flask가 0.0.0.0에 bind되어 EC2의 network interface들로 들어오는 요청을 받을 준비 **+** Security Group이 해당 port 허용
- **systemctl start** = 지금 실행 / **systemctl enable** = boot 시 자동 시작 등록
- 처음 실제 환경에서 확인한 흐름:
  browser → network → Security Group → Flask → MongoDB → response → JavaScript/DOM
