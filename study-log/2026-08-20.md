# JavaScript JSON 학습 일지

## 한 줄 요약

JSON 문자열을 `JSON.parse()`로 JavaScript 값으로 바꾸고, 그 값을 DOM에 표시하는 흐름을 학습했다. 그리고 값을 계산하는 함수와 화면을 변경하는 함수의 역할을 분리했다.

---

## 오늘 한 일

**1. JavaScript 객체와 JSON 문자열의 차이**

JavaScript 객체는 `.price`처럼 property에 바로 접근할 수 있다. 하지만 JSON은 문자열이기 때문에 그대로 property에 접근할 수 없다.

**2. 두 방향의 변환**

- `JSON.stringify()` : JavaScript의 객체나 배열 → JSON 문자열
- `JSON.parse()` : JSON 문자열 → JavaScript에서 사용할 수 있는 객체나 배열

**3. 값에 접근하는 순서**

객체 배열 형태의 JSON 문자열을 `JSON.parse()`한 뒤에는, 이전에 배운 것과 같은 순서로 접근할 수 있었다.

`JSON 문자열 → JSON.parse() → 배열 → 객체 → property → 값`

**4. JSON과 DOM 연결**

버튼을 클릭하면 JSON 문자열을 배열로 변환한 뒤, 객체의 property 값을 `querySelectorAll()`로 가져온 여러 DOM 요소의 `textContent`에 넣어 화면에 표시하는 흐름을 확인했다.

**5. CS : 직렬화와 역직렬화**

`JSON.stringify()`는 직렬화 방향, `JSON.parse()`는 역직렬화 방향이다. 프로그램에서 사용하는 데이터를 저장하거나 전달할 수 있는 형태로 변환하고, 다시 프로그램에서 사용할 수 있는 형태로 복원하는 과정이다.

**6. 알고리즘 : 변환과 순회는 다른 역할**

JSON을 변환하는 것과 배열을 순회하는 것은 서로 다른 역할이다. 배열의 모든 객체를 확인하면서 조건을 만족하는 개수를 세는 방식은, 데이터가 `n`개일 때 최대 `n`개를 확인하므로 시간복잡도가 `O(n)`이다.

---

## 시도한 것 (독립 재현)

JSON 문자열로 주어진 도서 데이터를 버튼 클릭 후 화면에 표시하는 프로그램을 만들었다.

- `booksJson`을 `JSON.parse()`하여 객체 배열로 만들었다.
- 반복문을 사용하여 각 객체의 `title`과 `price` property 값을 여러 DOM 요소에 표시했다.
- 20,000원 이하인 도서의 개수를 계산하는 함수를 따로 만들었다.

계산 함수에서는 DOM을 직접 변경하지 않고, 조건을 만족하는 개수를 계산한 뒤 숫자를 `return`했다. 반환된 값은 다른 함수에서 받아 DOM의 `textContent`를 변경했다.

이번 독립 재현에서는 새 변수를 만들 때 `const`와 `let` 선언을 빠뜨리지 않았고, 실제 데이터에 존재하는 `title`, `price` property 이름도 정확하게 사용했다.

## 막힌 부분

오늘 큰 구현 실패는 없었다.

다만 설명할 때, DOM 요소와 그 DOM 요소를 저장한 JavaScript 변수를 정확히 구분하지 못한 부분이 있었다.

`resultElement`는 HTML 요소의 이름이 아니다. `document.querySelector("#result")`가 반환한 DOM 요소를 저장한 JavaScript 변수라고 설명해야 한다.

---

## 배운 것

**`JSON.parse()`는 원본을 바꾸지 않는다.**

전달받은 원래 문자열 변수를 배열이나 객체로 직접 바꾸는 것이 아니라, 문자열을 분석하여 새로운 JavaScript 값을 반환한다. 따라서 `JSON 문자열 → JSON.parse() → 배열 → 객체 → property → 값` 순서로 생각해야 한다.

**함수의 역할을 구분한다.**

함수가 값을 계산하는 역할을 맡았다면 계산 결과를 `return`하고, DOM을 변경하는 역할은 다른 위치에서 수행하도록 한다.

**`const`와 `let`은 재할당 여부로 고른다.**

변수를 선언할 때는 먼저 새 변수인지 확인하고, 이후 재할당 여부에 따라 구분한다. `const`는 단순히 "새 변수라서" 사용하는 것이 아니라, 새 변수를 선언하면서 이후 재할당하지 않을 때 선택한다. 반복하면서 값이 변하는 `i`나 `count` 같은 변수는 `let`을 사용한다.

## 아직 부족한 부분

코드의 실행 결과를 판단하는 것은 비교적 잘 되었지만, 코드의 관계를 말로 설명할 때 표현을 더 정확하게 할 필요가 있다. 특히 다음을 계속 확인한다.

- DOM 요소와 그 DOM 요소를 저장한 JavaScript 변수의 차이
- 실제로 선언된 변수명과 property 이름 확인
- `>=`, `<=` 같은 조건을 말로 설명할 때 포함 범위를 정확하게 표현하기
- 함수가 맡은 역할과 `return`해야 하는 값을 요구사항과 함께 확인하기

3. 함수가 계산을 담당하는지 화면 변경을 담당하는지 요구사항을 먼저 확인한 뒤 작성한다.
