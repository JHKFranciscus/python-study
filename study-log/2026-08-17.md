# JavaScript 공부일지 — 변수·조건문 기초와 DOM/event 연결

## 한 줄 요약

JavaScript의 변수와 조건문 기초를 익히고, `querySelector()`로 찾은 요소를 `addEventListener()`와 `textContent`로 바꿔 실제 화면을 변경했다.

---

## 오늘 한 일

**1. 환경 연결**
- External JavaScript를 HTML에 연결하고 Console에서 실행되는 것을 확인했다.

**2. 문법 기초**
- `let`, `const`, 자료형, `typeof`를 학습했다.
- 비교 연산자·논리 연산자와 `if / else if / else`로 조건을 나누는 방법을 학습했다.

**3. DOM과 event**
- `querySelector()`로 DOM 요소를 찾고 `textContent`로 내용을 변경했다.
- `addEventListener()`를 이용해 버튼 클릭 후 페이지의 문구가 바뀌도록 구현했다.

**4. 알고리즘**
- 인접한 두 값의 차이를 비교해 가장 큰 증가량을 추적했다.

**5. CS**
- HTML을 읽어 DOM을 만든 뒤 → JavaScript가 실행되고 → event를 통해 DOM이 변경되어 → 화면에 반영되는 흐름을 정리했다.

---

## 막힌 부분

1. 같은 이름의 변수를 다시 선언해 오류가 발생했다.
2. `hasCoupon`과 `!hasCoupon`을 혼동해 조건의 의미를 반대로 작성했다.
3. `textContent`를 property가 아니라 method처럼 작성했다.
4. 독립 재현에서 `addEventListener()`에 클릭 event와 실행할 함수를 연결하는 구조를 바로 만들지 못했다.

---

## 시도한 것

1. **변수·값 확인** — 같은 이름을 다시 선언한 오류는 변수명을 바꿔 해결했고, 값과 자료형·비교식 결과가 헷갈릴 때는 실제 값을 하나씩 추적하며 Console 결과와 비교했다.
2. **논리 조건** — 값을 여러 조합으로 바꿔 `수강 가능 / 불가`가 예상대로 나오는지 확인했다.
3. **DOM과 event** — 독립 재현에서 막힌 뒤 설명을 다시 확인하고, event 함수 안에 조건문과 DOM 변경 코드를 연결해 수정했다.
4. **알고리즘** — 현재 index와 다음 index를 사용하는 방식, 이전 index와 현재 index를 사용하는 방식 두 가지로 구현했다.

---

## 배운 점

1. 변수는 이름보다 **현재 어떤 값이 들어 있는지**를 먼저 봐야 한다.
2. 논리식은 각 조건이 무엇을 의미하는지 **먼저 나눈 뒤** `&&`, `||`, `!`로 연결해야 한다.
3. `querySelector()`로 요소를 찾고, event가 발생했을 때 등록된 함수에서 `textContent`를 변경하면 실제 화면을 바꿀 수 있다.
4. `addEventListener()`로 함수를 **등록하는 시점**과 event 발생 후 함수가 **실행되는 시점**은 다르다.

---

## 아직 부족한 부분

- 오늘 배운 DOM 관련 코드를 각각 이해하는 것과, **요소 찾기 → event 등록 → 조건 판단 → DOM 변경**을 완성 코드 없이 한 번에 연결하는 것은 별개의 문제였고 후자는 아직 부족하다.
- `querySelector()`·`addEventListener()` 같은 method와 `textContent` 같은 property를 코드 작성 중 바로 구분하는 연습이 더 필요하다.
- 오늘 독립 재현은 처음부터 성공하지 못했고, 핵심 구조를 안내받은 뒤 보완했다.

## 면접용 3줄 정리

1. **변수** — 변수 이름보다 현재 들어 있는 값을 추적해야 한다. 같은 이름을 다시 선언한 오류는 선언 위치와 이름을 확인해 수정했고, 값과 자료형은 Console로 확인했다.
2. **조건문** — `hasCoupon`과 `!hasCoupon`을 혼동했다. 조건의 의미를 먼저 나눈 뒤 연산자로 연결하는 순서로 고쳤다.
3. **DOM/event** — `querySelector()`로 찾고, `addEventListener()`로 등록하고, `textContent`로 바꾼다. 등록하는 시점과 실행되는 시점이 다르다는 것이 핵심이다.
