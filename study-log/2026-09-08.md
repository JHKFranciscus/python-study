막힌 점

강의 목록 독립 구현에서 Flask/MongoDB의 큰 구조는 직접 구성했지만 JavaScript 세부 연결에서 오류가 발생했다.

DOM element와 .value 혼동
query string과 완성된 request URL 혼동

DOM element와 innerHTML 혼동
선택값을 function 밖에서 한 번만 읽어 변경된 값이 반영되지 않는 구조 작성
collection → element 하나를 추적하는 문제에서 일부 오류

<select>의 value는 조회 function이 실행될 때마다 다시 읽도록 수정했고, change event에 function 자체를 등록했다.

수정 후 브라우저에서 전체 / beginner / intermediate와 정렬 여부를 바꿔가며 실제 동작을 확인했다.

배운 점

GET request의 query string을 Flask의 request.args로 읽고 그 value를 MongoDB 조건 dictionary에 연결할 수 있다.

또한 client와 server가 같은 변수를 공유하는 것이 아니라 value가 HTTP request를 통해 단계별로 전달되는 것이라는 점을 확인했다.

긴 코드를 작성할 때는 변수 이름만 보고 연결하지 말고 다음 순서로 판단해야 한다.

현재 value
→ type
→ 지금 필요한 값의 종류
→ 그 값을 가진 변수
→ 다음 parameter
아직 모르는 점

새 문법보다 긴 코드에서 다음 구분을 끝까지 안정적으로 유지하는 것이 아직 부족하다.

DOM element / value
collection / element
query string / request URL
function / function 호출 결과
Cursor / list

강의 목록 조회 기능은 최종적으로 정상 동작했지만 여러 세부 연결을 교정받았으므로 완전 독립 재현 성공은 아니다.
