1. enumerate()는 무엇을 같이 꺼내기 위해 사용하는가?
순번과 값을 같이 꺼내기 위하여 사용한다.

2. zip()은 무엇을 하는 함수인가?
두 종류 이상의 iterable의 요소를 index 위치에 맞춰 묶는 함수

3. iterable과 iterator의 차이는 무엇인가?
iterable은 순차적으로 요소를 순회할 수 있는 목록이라면,
ierator는 iterable을 한번만 사용할 수 있게 만든 것이다.
# 수정 후
iterable은 iter()로 iterator를 만들 수 있는 객체
iterator는 next()를 호출할 때마다 다음 값을 하나씩 꺼내는 객체

4. iter()와 next()는 각각 무슨 역할을 하는가?
iter()는 iterble을 iterater로 만드는 역할을 한다.
next는 iterable의 요소를 다음으로 진행하는 역할을 한다.
# 수정 후
next()는 iterator에게 다음 값을 요청한다.
그리고 더 이상 값이 없으면 StopIteration이 발생한다.

5. generator 함수에서 yield가 실행되면 무슨 일이 일어나는가?
yield의 값을 반환하고 generator 함수를 yield에서 일시 중지한다.

6. 함수 객체를 전달하는 것과 함수를 호출한 결과를 전달하는 것은 어떻게 다른가?
함수 객체를 전달하는 것은 함수 객체를 이용하여 다른 작동들을 시험해 볼 수 있지만
함수를 호출한 결과를 전달하는 것은 그 결과의 값만 사용할 수 있다.
# 수정 후
함수 객체를 전달하면 함수 자체가 전달되어 전달받은 곳에서 나중에 호출할 수 있고, ()를 붙이면 함수가 즉시 실행되어 그 반환값이 전달된다.

7. decorator는 기존 함수에 어떤 방식으로 기능을 추가하는가?
기존 함수를 decorate한 함수의 매개변수에 집어 넣는 방식으로 기능을 추가한다.
# 수정 후
기존 함수를 수정하지 않고, 기존 함수를 감싼 새로운 함수를 만들어 기존 함수의 기능을 추가한다.

8. @dataclass를 사용하면 일반 class에서 직접 작성하던 것 중 무엇을 자동으로 만들어주는가?
별도로 설정하지 않은 특수 method를 자동으로 만들어준다.
# 수정 후
데이터를 보관하는 class에서 __init__, __repr__, __eq__ 같은 반복적인 특수 메서드를 자동으로 만들어준다.

9. Python에서 module과 package의 차이는 무엇인가?
module은 하나의 파일을 의미하고, package는 여러 개의 module을 뭉쳐놓은 것을 의미한다.

10. 가상환경과 requirements.txt는 각각 왜 사용하는가?
다른 사람에게 내 가상환경 폴더를 통채로 건너는 것이 아니라 프로그램 코드와 requirements.txt(pip 목록)을 건내주게 되면, 그 사람의 컴퓨터에서 가상환경을 생성한 후 그 사람의 컴퓨터 가상환경에서 목록을 install할 수 있기 때문이다.
# 수정 후
가상환경은 프로젝트마다 Python 패키지 설치 환경을 분리하기 위해 사용하고
requirements.txt는 프로젝트에 필요한 패키지와 버전을 기록해두는 파일이다.
