# 3주차 주간 학습 기록

## 이번 주 배운 내용

이번 주에는 문자열 입력 정규화, 텍스트 파일 처리, JSON 저장, 예외 처리와 모듈 분리를 학습했다.

`strip()`과 `lower()`를 사용해 앞뒤 공백과 영문 대소문자 차이를 정리했고, 키워드가 전체 문자열과 일치하지 않아도 찾을 수 있도록 부분 검색을 구현했다.

또한 리스트를 처음부터 확인하는 순차 검색의 `O(n)`과 딕셔너리 키 조회의 `O(1)`을 비교했다.

텍스트 파일에서는 `r`, `w`, `a` 모드의 차이를 학습하고, 파일을 기반으로 메모를 추가·조회·검색·수정·삭제하는 기능을 구현했다.

JSON에서는 `json.dump()`와 `json.load()`를 사용해 리스트와 딕셔너리 데이터를 저장하고 불러왔다. 파일이 없거나 JSON 형식이 잘못됐거나 숫자로 변환할 수 없는 입력이 들어오는 상황을 `FileNotFoundError`, `JSONDecodeError`, `ValueError`로 구분해 처리했다.

프로그램이 커지면서 파일을 `main`, `service`, `storage`로 분리했다.

- `main`: 사용자 입력·출력, 문자열의 정수 변환, 최종 오류 안내
- `service`: 검색·추가·수정·삭제 등의 데이터 처리
- `storage`: JSON 파일 불러오기와 저장

이 과정에서 하위 함수가 처리하지 않은 예외가 상위 호출자로 전파되는 과정도 확인했다.

## 만든 프로그램

이번 주에는 다음 프로그램을 만들었다.

1. 텍스트 파일 기반 메모 관리 프로그램
2. JSON 기반 학습 기록 프로그램
3. 모듈형 도서 관리 프로그램

모듈형 도서 관리 프로그램에는 전체 조회, 도서 추가, 제목 검색, 가격 수정, 도서 삭제, JSON 저장과 불러오기 기능을 구현했다.

주간 복습에서는 기존 코드를 보지 않고 `main`, `service`, `storage` 구조를 다시 작성했다.

## 가장 많이 막힌 부분

검색 함수가 검색 결과 자체를 반환하지 않고 `True` 또는 `False`만 반환하도록 만들어서, `main`에서 같은 검색을 다시 수행하는 구조가 생겼다.

가격을 정수로 변환하는 코드와 `ValueError` 처리를 `service`와 `main` 중 어디에 두어야 하는지도 구분하지 못했다.

JSON 데이터를 만들 때에는 딕셔너리를 만들려다가 중괄호 안에 값만 나열해 `set`을 만들었다.

```python
{"topic", topic}     # set
{"topic": topic}     # dictionary
```

SSAFY 문제에서는 25문제 중 13문제를 맞히고 12문제를 틀렸으며, 다이나믹 프로그래밍 유형에서 가장 많이 틀렸다.

## 문제의 원인

처음에는 프로그램이 실행되는지만 확인하면서 함수의 입력값, 반환값과 각 모듈의 역할을 작성 전에 정하지 않았다.

그 결과 파일 처리, 데이터 처리, 사용자 입력과 출력이 여러 모듈에 섞였고, 같은 기능을 `main`과 `service`에서 반복하는 코드가 생겼다.

## 직접 확인하고 수정한 과정

프로그램을 정상적인 입력으로만 실행하지 않고 다음과 같은 실패 상황을 직접 만들어 확인했다.

- 파일이 없는 상태에서 실행
- 빈 문자열 입력
- 영문 대소문자가 다른 검색어 입력
- 숫자 자리에 `abc` 입력
- JSON 파일 내용을 잘못된 문자열로 변경
- 프로그램 종료 후 다시 실행해 데이터 유지 여부 확인
- 검색·수정·삭제할 때 제목의 대소문자를 다르게 입력

이후 역할을 다음과 같이 다시 나눴다.

- 파일 읽기와 저장은 `storage`
- 검색·추가·수정·삭제는 `service`
- 사용자 입력·출력, 정수 변환과 오류 안내는 `main`

검색 함수는 `True`나 `False`가 아니라 검색된 도서 목록을 반환하도록 수정했다.

가격 입력은 `main`에서 `int()`로 변환하고, `ValueError`가 발생하면 프로그램이 종료되지 않고 메뉴로 돌아가도록 했다.

## 실제 실행 결과

다음 동작을 확인했다.

- `Python Basics`를 `PYTHON`으로 검색해도 결과가 출력됐다.
- `python basics`를 입력해도 가격 수정과 삭제가 가능했다.
- 가격에 `abc`를 입력해도 프로그램이 종료되지 않았다.
- JSON 파일을 망가뜨려도 traceback 없이 빈 목록으로 시작했다.
- 도서 가격을 수정한 뒤 프로그램을 재실행해도 수정 결과가 유지됐다.

## 아직 부족한 부분

아직 함수를 작성하기 전에 반환값을 결정하거나, 모듈 역할과 예외 처리 위치를 처음부터 설계하는 능력이 부족하다.

SSAFY 문제에서는 다이나믹 프로그래밍 문제의 상태와 점화식을 찾는 연습이 더 필요하다.
