1. 사용자가 입력한 검색어에 strip()과 lower()를 적용한 이유는 무엇인가?
입력 정규화를 하여 검색어와 비교대상을 비교대상을 비교하기 쉽게 만드는 것이다.
[수정 후]
strip()은 입력 문자열의 앞뒤 공백과 줄바꿈 문자를 제거한다.
lower()는 영문 대문자를 소문자로 바꾸어 대소문자 차이 없이 비교하기 위해 사용한다.
검색어와 비교 대상에 같은 정규화를 적용하면 입력 형식이 조금 달라도 검색할 수 있다.
2. 리스트에서 키워드를 하나씩 확인하는 검색이 일반적으로 O(n)인 이유는 무엇인가?
리스트에서 키워드를 하나씩 확인하면 순차적으로 요소를 하나씩 비교하는데, 최악의 경우 모든 요소를 전부 비교해야하기 때문이다.
3. 파일 모드 r, w, a는 각각 어떤 상황에서 사용하는가?
r모드는 파일의 내용을 읽을 때만 사용한다. w모드는 파일의 내용 전체를 다시 작성할 때 사용한다. a모드는 파일의 마지막에 내용을 추가할 때 사용한다.
[수정 후]
r모드는 기존 파일의 내용을 읽을 떄 사용하며, 파일이 없으면 FileNotFoundError가 발생한다.
w모드는 파일 내용을 처움부터 다시 저장할 때 사용하며, 기존 내용은 사라진다. a모드는 기존 내용의 마지막에 새 내용을 추가할 때 사용한다.
w와 a모드는 파일이 없으면 새 파일을 만든다.
4. 텍스트 파일의 특정 메모를 수정하거나 삭제할 때, 보통 파일 전체를 다시 저장해야 하는 이유는 무엇인가?
파일을 받아서 분리해서 원하는 요소만 수정하거나 삭제한 후, 다시 저장하는 부분 전체를 하나의 새로운 iterble로 만들어서 저장하기 때문이다.
5. json.dump()와 json.load()는 각각 무엇을 하는 함수인가?
json.dump()는 파이썬 객체를 직렬화하여, JSON형식의 파이썬 문자열로 만든 후에 그걸 파일에 저장하는 함수이다., json.load()는 JSON형식으로 저장되어 있는 파일의 내용을 복사하여, JSON형식의 파이썬 문자열을 만들어준 후 그것을 역직렬화하여 파이썬 객체를 만들어주는 것이다.
[수정 후]
json.dump()는 파이썬 객체를 JSON 형식으로 직렬화하여 파일에 저장하는 함수이다. json.load()는 파일에 저장된 JSON 데이터를 읽고 역직렬화하여 파이썬 객체로 만드는 함수이다.
6. 다음 예외가 발생하는 대표적인 상황을 각각 설명한다.
FileNotFoundError: 파일자체가 존재하지 않는 경우
JSONDecodeError: 파일은 존재하는데 내용이 비어있거나, 내용이 JSON형식이 아닌 잘못된 형식인 경우
ValueError: type에 맞지 않는 값이 들어가 있는 경우
[수정 후]
ValueError: 연산이 요구하는 자료형은 맞지만, 그 연산에 사용할 수 없는 값이 들어온 경우 발생한다. 
7. 예외 전파란 무엇인가?
어떤 method에서 예외가 발생하였는데, 그 method에서 예외를 처리하지 못하여 그 method를 호출한 상위 method로 예외가 올라가는 상황이다. 이는 예외를 처리하는 코드를 만날 때까지 호출스택을 타고 올라가며, 끝까지 해결하지 못하면 런타임이 해결하며, traceback이 뜨며 프로그램이 비정상적으로 종료된다.
8. 모듈형 프로그램에서 다음 파일의 역할을 각각 설명한다.
main => 프로그램의 직접적인 실행부
service => 프로그램에서 계산 및 입출력을 담당
storage => 파일을 읽거나 파일에 저장을 담당
[수정 후]
main => 사용자 입력을 받고 결과를 출력하며, 필요한 service 함수를 호출한다.
service => 검색·추가·수정·삭제·입력 검증 등 프로그램의 핵심 처리 규칙을 담당한다.
storage => 파일에서 데이터를 불러오거나 파일에 저장하는 작업을 담당한다.
